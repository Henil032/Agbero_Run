# Agbero Run — Eko Traffic Edition V8 (Mobile Friendly)

## What's included
- Lagos-inspired 3D endless runner with moving traffic, buses, intersections, coins, and fair-traffic protection.
- Mobile touch buttons for left, jump, duck, and right.
- Swipe controls: swipe left/right to change lanes, up to jump, and down to duck; a tap on the road jumps.
- Responsive layout for portrait and landscape screens, including safe-area spacing for newer phones.
- Reduced rendering resolution and disabled real-time shadows on mobile-sized devices to help performance.
- Keyboard controls remain available on desktop.

## Run locally
1. Extract the ZIP.
2. Open the `AgberoRun_V5` folder in VS Code.
3. Open `index.html` with Live Server.
4. Keep an internet connection on because Three.js and fonts load from CDNs.

## Controls
- PC: Left/Right arrows or A/D to change lanes; Space, Up arrow, or W to jump; Down arrow or S to duck; P or Escape to pause.
- Mobile: Use the four on-screen touch buttons, or swipe left/right/up/down on the game scene. Tap the game scene to jump.

## Publishing
Upload the contents of this folder (`index.html`, `style.css`, `script.js`, and `README.md`) to the root of a GitHub Pages repository. The game runs in a mobile browser; no Web-to-App converter is required. An internet connection is needed for the Three.js CDN.

Mobile performance varies by device and browser, so test it on the phones you want to support before announcing it publicly.
